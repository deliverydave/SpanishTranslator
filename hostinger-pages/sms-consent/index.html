Optional SMS enrollment

Bilingual messaging add-on — not required to use DeliveryDave

SMS is optional. Consent to text messages is not required to purchase or use DeliveryDave. You can use DeliveryDave (including the web translator at translate.deliverydave.ai) without enrolling in SMS. This page is only if you want the optional bilingual SMS bridge.

DeliveryDave is a contractor operations platform. Separately, DeliveryDave offers an optional bilingual SMS translation feature so the business may coordinate with Spanish-speaking crew, vendors, or customers by text.

If you opt in to SMS

  • Operational messages only (scheduling, materials, job updates) — not marketing
  • Each number receives texts in the language selected below (English or Spanish)
  • Message frequency varies. Message and data rates may apply.
  • Reply STOP to cancel. Reply HELP for help.
